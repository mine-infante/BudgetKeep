# Purpose

Define the official identification standard for all project artifacts generated throughout the AI MineSoftware methodology.

The objective is to ensure consistency, traceability and unambiguous communication across every project phase.

# Naming Rules

- Identifiers are unique.
- Identifiers are never reused.
- Deleted artifacts are never renumbered.
- Every identifier is permanent.
- References between artifacts shall use their identifiers.

---

# Governance

The Project Office owns and maintains this standard.

All specialists shall use this naming convention.
